# Daniel D’Souza resume

Based on Jake Gutierrez’s MIT-licensed Jake’s Resume template: https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs and https://github.com/jakegut/resume. Adapted with right-aligned dates in normal text flow, Charter fonts, standard section headings, and separately identified employer entries. The conditional PDF primitives also permit the desktop editor’s XeTeX-based compiler.

Edit main.tex. Compile with pdflatex main.tex (twice for links), or use the Codex LaTeX editor. The checked final PDF is copied to ../output/pdf/Daniel D'Souza Resume.pdf and ../public/assets/documents/Daniel D'Souza Resume.pdf. Cloudflare has not been updated.

Sources: preserved original-resume.pdf, current portfolio data, user-provided school dates/honors, and the Boilerplate Devpost description. Updated Stony Brook graduation to May 2029 and used the university email. Kept all employers and a selection of leadership/awards; included Boilerplate instead of repeating the ReWild projects. No GPA for Stony Brook or unverified impact metrics were added.
